# 健康档案小程序 MVP

这是一个原生微信小程序 MVP，用来记录个人体检、门诊、检查报告和处方信息。当前版本使用微信小程序本地缓存保存数据，不需要后端即可在微信开发者工具中运行。

## 页面

- 首页：查看记录数量、最近记录和快捷入口
- 记录列表：按类型筛选、关键词搜索、进入编辑
- 新增记录：录入体检、门诊、检查报告、处方等信息，添加图片或文件附件
- 医生查看：汇总过敏史、既往病史、长期用药和近期记录
- 个人档案：维护基础信息、病史、联系人等

## 运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹：`/Users/chenxi/Documents/New project`。
4. AppID 可以先使用测试号，或保留 `project.config.json` 中的 `touristappid` 进行本地体验。
5. 点击“编译”运行。
