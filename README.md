# 健康档案小程序 MVP

这是一个原生微信小程序 MVP，用来给本人和家人记录体检、门诊、检查报告和处方信息。当前版本使用微信小程序本地缓存保存数据，不需要后端即可在微信开发者工具中运行。

## 页面

- 记录列表：按家庭成员、类型和关键词筛选，进入编辑
- 新增记录：录入体检、门诊、检查报告、处方等信息，添加图片或文件附件
- 个人档案：按列表管理本人和家人，点进列表项维护基础信息、病史、联系人等
- 健康建议：在档案页展示日常饮食、运动频率和复诊准备建议

## 运行

1. 安装并打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择当前文件夹：`/Users/chenxi/Documents/New project`。
4. AppID 可以先使用测试号，或保留 `project.config.json` 中的 `touristappid` 进行本地体验。
5. 点击“编译”运行。

## 照片识别

- 点击附件里的“识别内容”需要先开通微信云开发，并在微信开发者工具里上传并部署 `cloudfunctions/ocrReport` 云函数。
- `cloudfunctions/ocrReport/config.json` 已声明 `ocr.printedText` 权限；如果仍提示没有权限，请重新上传部署云函数，并确认当前 AppID 已开通 OCR 能力。
- 图片使用微信 OCR 识别；带文字层的 PDF 由云函数直接提取文字。
- 扫描型 PDF 如果没有文字层，需要先将报告页面保存为图片后再识别。
